# baharal-hugoblox

The Hugo theme of the Menashe Forge sites, forked from [HugoBlox/kit](https://github.com/HugoBlox/kit) (MIT, `LICENSE.md`). The theme is `modules/blox`. Rules, options and how to ship a change: `MENASHE-FORGE.md`.

To refresh the bundled JS libraries in `modules/blox/assets/dist/lib`: `pnpm install && pnpm vendor:libs`.
